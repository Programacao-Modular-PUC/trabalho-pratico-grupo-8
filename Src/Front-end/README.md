# Front-end · Pousadas de Maraú

Front-end do sistema de hospedagem feito em HTML e CSS puros.

## Estrutura

```
Front-end/
├── css/        → folha de estilo global (estilo.css)
├── js/         → scripts JavaScript
├── imagens/    → imagens do site
├── index.html  → redireciona para login
├── login.html
├── cadastro.html
├── residencias.html
└── quartos.html
```

## Como abrir

Abrir o `index.html` (ou `login.html`) direto no navegador.
